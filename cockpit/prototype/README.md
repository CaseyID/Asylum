# Cockpit UI Prototype

This is a PROTOTYPE of the Cockpit UI for Asylum. It was generated with Claude Design. It should be taken as a source of truth for behavior INTENTION and design system/language INTENTION - the actual IMPLEMENTATION will obviously differ when we build out Cockpit for Asylum in real life.

That means you must ignore/properly reason about:
- Things that are mocked or simulated in the prototype: these should obviosly not be mocked/simulated in the actual implemation of Cockpit, they should be actually built out and functional.
- Things like the "tweaks" panel that are part of the claude design workflow/process, these are obviously NOT part of the real Cockpit UI.
- Any other common sense things that should not be carried over from a PROTOTYPE to the actual implementation of Cockpit.

This is the source of truth for the Cockpit UI, but again, it is a mocked up prototype, the actual Cockpit UI must actually be implemented with all of the functionality and behavior shown in the prototype (using common sense and reasoning to understand what is prototype only vs. what we actually want implemented).
